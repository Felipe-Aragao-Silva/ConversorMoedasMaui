## 📖 Descrição

O **Conversor de Moedas MAUI** é um aplicativo multiplataforma desenvolvido com .NET MAUI que permite converter valores entre diferentes moedas de forma rápida e intuitiva. O projeto tem como objetivo demonstrar conceitos de desenvolvimento mobile moderno utilizando C#, integração com APIs externas e interface responsiva.

## ⚙️ Pré-requisitos

Antes de começar, você precisa ter instalado:

- .NET SDK 8.0 ou superior
- Visual Studio 2022+ com workload:
  - .NET MAUI
- Emulador Android ou dispositivo físico (opcional)

## 📦 Instalação e Execução

```bash
# Clone o repositório
git clone https://github.com/Felipe-Aragao-Silva/ConversorMoedasMaui.git

# Acesse a pasta
cd ConversorMoedasMaui

# Restaurar dependências
dotnet restore

# Build do projeto
dotnet build
```

---

## 💡 Como Usar
1. Abra o aplicativo
2. Insira o valor
3. Escolha a moeda de origem
4. Escolha a moeda de destino
5. Veja o resultado

```
Valor: 100
De: BRL → Para: USD

Resultado: $19.85
```
